# Shopify Preorder

App Shopify para pré-vendas da TopFuel Garage.

Regras principais:

- A tag controla somente a quantidade máxima disponível para pré-venda.
- A previsão é individual por produto.
- Produtos diferentes podem compartilhar a mesma tag e ter previsões diferentes.
- O fluxo de pagamento deve usar checkout normal da Shopify para manter compatibilidade com Mercado Pago/PIX.
